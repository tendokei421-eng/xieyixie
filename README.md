# 歇一歇

工作中记得歇一歇。安排每天的日程，在空闲里晒太阳、看风景、慢慢呼吸。

## 能做什么

- **歇一歇**：看今天的松弛度，按当前节奏推荐一小段休息（晒太阳、看窗外、伸懒腰等）
- **今天**：按日期添加、编辑、复制、删除日程；有安排时才会标出可歇的空隙
- 休息开始后有倒计时，结束后记入今天已歇的次数

## 本地运行

需要 Node.js 22。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

日程保存在浏览器本地，不需要登录。

## 技术栈

React 19、TanStack Start、Tailwind CSS v4、Zustand。
